Architecture & Description:The FIR filter is a cornerstone of Digital Signal Processing (DSP). This specific task implements a 4-tap FIR filter using a Direct Form architecture. It calculates the output $y[n]$ using the convolution formula:$y[n] = b_0x[n] + b_1x[n-1] + b_2x[n-2] + b_3x[n-3]$The hardware uses cascaded D-Flip-Flop shift registers to delay the incoming 8-bit data ($x[n]$). In a single clock cycle, it multiplies these historical data points by predefined coefficients ($b_0=1, b_1=2, b_2=2, b_3=1$) and sums them using an adder tree (a Multiply-Accumulate or MAC operation). Because the coefficients are strictly positive, this acts as a low-pass filter (moving average), smoothing out high-frequency noise.
Applications & Real-World Use:Digital FIR filters are critical in environments where phase linearity (zero phase distortion) is required. 
They are heavily utilized in:Telecommunications: Software Defined Radios (SDR) and 5G base stations for signal modulation and noise rejection.Audio Processing: Equalizers, digital crossovers, and echo cancellation in headphones and microphones.
Biomedical Engineering: Filtering out powerline interference (50/60Hz hum) from ECG/EEG heart and brain monitors.
Sensor Fusion: Smoothing noisy analog-to-digital (ADC) sensor readings in robotics and aerospace telemetry.
